Accordion Populator

How to use:
1. Make sure your Accordion in Elementor has enough items already.
2. Ensure that each accordion item contains a Text Editor widget (this tool doesn't currently support other widgets).
3. Copy the accordion widget and paste it in box #2.
4. Click the button and use "Paste from other site" in Elementor.

Note: Does not yet support text formatting (for bolding, links, etc.).
