Elementor Icon List Populator

How to Use

  1. Prepare Elementor: Create an Icon List widget with enough items.
  2. Input Content: Paste your list into the editor above. Adjust formatting if needed.
  3. Paste Widget Code: Copy your Icon List widget from Elementor and paste the code into the bottom box.
  4. Process: Click "Populate List" and then use "Paste from other site" on your widget in Elementor.
